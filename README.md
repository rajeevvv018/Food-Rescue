# 🍱 FoodRescue

> Turning Surplus Food into Social Impact.

FoodRescue is a Java-based surplus food redistribution platform
connecting food providers, NGOs, and volunteers to reduce food waste
and support food redistribution.

## 🚧 Project Status

Currently in development.

## 🛠️ Tech Stack

Java • Jakarta Servlet • JSP • JDBC • MySQL • Maven • Tomcat
